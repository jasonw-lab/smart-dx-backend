実行コマンド

OrbStack 環境では Testcontainers に Docker socket を明示する。

export DOCKER_HOST="unix://$HOME/.orbstack/run/docker.sock"
export TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock

統合 app E2E

cd apps/backend
mvn -pl app -Dtest=AuthE2ETest,MultiTenantIntegrationTest,TenantIsolationSecurityTest test

system-be E2E

cd apps/backend
mvn -pl services/system-be -Dtest=AuthE2ETest test

retail-be E2E

cd apps/backend
mvn -pl services/retail-be -Dtest=AlertAssistantE2ETest,AlertE2ETest,DashboardE2ETest,DeviceE2ETest,InventoryE2ETest,ProductE2ETest,SalesE2ETest test

property-be E2E

cd apps/backend
mvn -pl services/property-be -Dtest=PropertyBulkImportE2ETest,PropertyCreateE2ETest,PropertyImageSearchE2ETest,PropertyOpenSearchE2ETest,PropertySearchE2ETest,PropertySimilarSearchE2ETest,ChatbotSearchE2ETest test

注意事項

OpenSearch 系 property E2E: PropertyOpenSearchE2ETest と PropertySimilarSearchE2ETest は OpenSearch availability check に依存し、利用不可の場合は assumeTrue によりスキップされる。

retail AI E2E: application-e2e.yml で retail.ai.llm.provider=local を指定し、外部 LLM API へ到達しない。

Docker socket: macOS + OrbStack では DOCKER_HOST=unix://$HOME/.orbstack/run/docker.sock の明示が必要な場合がある。
